# sveak-test-task
Тестовое задание на позицию Frontend-разработчик/Верстальщик

https://elenabauman.github.io/sveak-test-task/

## Стек

- Vite
- HTML
- SCSS
- Handlebars

Для заполнения данными:
- TypeScript

## Запуск

```bash
yarn install
yarn dev
```

## Важно

- Есть два коммита: первый - все по базовому макету, без скриптов. Второй - с мок-данными (без API) и модалкой, с кастомизированными стилями. Во втором коммите используется TypeScript. В коде есть пара комментов для ревьюера.
